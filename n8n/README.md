# EduTrack n8n Automation Workflows

EduTrack uses n8n to demonstrate workflow automation and AI integration.

## 1. EduTrack Attendance Alert Automation

This workflow automates attendance-related alerts.

### Purpose

- Monitor student attendance information
- Trigger an automated workflow when an attendance condition is met
- Reduce manual attendance monitoring
- Provide timely attendance-related notifications

### Technology

- n8n
- EduTrack backend/data
- Automated workflow triggers

---

## 2. EduTrack AI Student Assistant Chatbot

This workflow provides an AI-powered student assistant for EduTrack.

### Purpose

The chatbot helps students get information and assistance related to their academic progress.

It can support queries related to:

- Attendance
- Marks
- Academic performance
- Best-performing subject
- Subjects requiring improvement
- Student academic information

### Technology

- n8n
- AI workflow
- EduTrack student data
- Automated response workflow

---

## Workflow Files

- `EduTrack_Attendance_Alert_Automation.json`
- `EduTrack_AI_Student_Assistant_Chatbot.json`

These JSON files contain the exported n8n workflows used in the EduTrack project.

## Important

The exported workflow files should not contain passwords, API keys, access tokens, or other sensitive credentials.
